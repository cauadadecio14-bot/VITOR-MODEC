Entrar

Primeiro acesso — criar login

  1. No GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Em “Repository access”, escolha Only select repositories → VITOR-MODEC. Em “Permissions → Repository permissions”, deixe Contents: Read and write.
  3. Cole o token abaixo e escolha um usuário e uma senha forte (mínimo 10 caracteres). O token é criptografado com a sua senha.
  4. Será baixado o arquivo acesso.js: envie-o para o repositório (Add file → Upload files). Depois disso o login funciona de qualquer computador.

Atualizar dados

  1. Selecione a planilha .xlsx atualizada (aba “Marinha”).
  2. Confira o resumo e os avisos abaixo.
  3. Clique em Publicar: o link da equipe é atualizado em cerca de 1 minuto.
